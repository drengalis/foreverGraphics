# Forever Graphics

A World of Warcraft: Forever (Camelot, interface `16001`) addon that exposes eight advanced graphics console variables through an in-game control panel.

<img width="1852" height="1144" alt="image" src="https://github.com/user-attachments/assets/f23e04dc-ef35-4202-80fa-e6863f986b78" />

## Features

- Eight sliders with minimum and maximum values displayed alongside the track.
- Selected (pending) value displayed above each slider.
- Current game value and configured default displayed for each setting.
- **Apply** and **Reset** for each row.
- An **info** icon with a description and performance notes for every setting.
- **Apply Suggested (8)** and **Reset All to Default**.
- Draggable panel with saved position.
- No automatic graphics changes when logging in.

## Installation

1. Download the installation ZIP from the [Releases](../../releases) page, **not** GitHub's autogenerated source-code ZIP.
2. Extract it into your WoW Forever `Interface/AddOns` directory, so the final structure is:

   ```text
   Interface/
   └── AddOns/
       └── ForeverGraphics/
           ├── ForeverGraphics_Camelot.toc
           ├── ForeverGraphics.lua
           └── README.txt
   ```

3. Enable **Forever Graphics** from WoW's AddOns list.
4. In-game, type `/fgfx` to open or close the panel.

## Commands

| Command | Description |
| --- | --- |
| `/fgfx` | Toggle the graphics settings window. |
| `/forevergraphics` | Alternative to `/fgfx`. |
| `/fgfx max` | Apply all eight suggested settings. |
| `/fgfx reset` | Prompt to reset all eight settings to their listed defaults. |
| `/fgfx refresh` | Re-read all current client values and discard pending slider edits. |

## Settings

| Console variable | Suggested | Reset default |
| --- | ---: | ---: |
| `groundEffectDensity` | 256 | 16 |
| `groundEffectFade` | 370 | 70 |
| `groundEffectDist` | 500 | 70 |
| `lodObjectFadeScale` | 200 | 100 |
| `lodObjectCullSize` | 8 | 15 |
| `terrainLodDist` | 1000 | 400 |
| `ResampleAlwaysSharpen` | 1 | 0 |
| `reflectionMode` | 3 | 3 |

The reset defaults are based on [Warcraft Wiki's console variable reference](https://warcraft.wiki.gg/wiki/Console_variables). Some WoW Forever builds may have different native defaults, particularly for `terrainLodDist` (500 instead of 400).

Sliders use practical UI ranges rather than guaranteed client engine limits. The client may reject or clamp some values; the addon reads values back after applying them.

## Notes

- Slider adjustments are pending until **Apply** is clicked.
- Individual **Reset** buttons apply immediately.
- A few visual settings may not take full effect until changing zones, relogging, or restarting the client.
- Removing the addon does not automatically undo graphics settings you already applied.
